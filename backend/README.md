# Grading System

An automated Grading System developed for our Capstone project. Built using Vue.js for a responsive and dynamic user experience.

## Tech Stack
- **Frontend:** Vue.js (Vue 3)
- **Styling:** Tailwind CSS / Vuetify
- **Version Control:** Git & GitHub

## Project Features
- **Student Dashboard:** View grades, academic progress, and student profile.
- **Professor Dashboard:** Encode, compute, and submit student grades per subject.
- **Grade Drafts:** Assessment scores and custom headers are automatically saved per course and restored when the professor returns; drafts are cleared after successful Registrar submission.
- **Grading Criteria:** Professors can set and save each category's maximum score (up to 100) and grading percentage, add independent custom categories, and configure each course's criteria; saved criteria are applied when grades are submitted.
- **Registrar Dashboard:** Manage student enrollment records, sectioning, and overall master list.
